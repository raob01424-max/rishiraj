# Rishiraj Kumar — Portfolio Website

A mobile-responsive, dark-themed personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and back-to-top interaction

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local development server, open the folder in VS Code and use the Live Server extension.

## Publish online with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `rishiraj-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your live URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/rishiraj-portfolio/`

You can also deploy the folder using Netlify Drop.
